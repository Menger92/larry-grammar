# 项目方法论：学习体系与实战分析分工

本项目的目标不是整理一套孤立讲义，而是形成一套可以拿去分析真实英文文章的语法判断系统。

## 三层结构

| 层级 | 作用 | 使用场景 | 维护原则 |
| --- | --- | --- | --- |
| Larry 主线 | 项目的学习顺序和判断引擎 | HTML 学习页、Markdown 主讲义、语法判断流程 | 保持主线稳定，不因补充材料随意重排章节。 |
| 文法俱乐部旁注 | 理论底座、术语来源、细节补强 | 遇到概念需要理论解释时查阅 | 先做章节对照，不大段搬入正文；等 Larry 视频资料稳定后逐章补旁注。 |
| 经济学人实战 | 用真实文章检验语法体系 | Codex 对话框中的句子分析 | 不做网页工作台；在对话中按固定流程输出分析。 |

## 当前结论

不要等所有 Larry 视频都补齐后才重构项目结构；但也不要现在就把《文法俱乐部》的细节大量写进各章节。

更稳的顺序是：

1. 现在先建立“书课对照、术语对照、分析协议”三类索引。
2. 后续继续补 Larry 视频资料，仍以 Larry 主线为准。
3. 等某一块 Larry 内容稳定后，再补对应的《文法俱乐部》旁注。
4. 在经济学人分析中反复卡住的点，优先回填到语法库。

## 判断优先级

分析句子时按以下顺序判断：

1. 先按 Larry 主线找谓语、定主干、判句型。
2. 再剥离定语、状语、补语、介词短语。
3. 遇到从句，先判断从句整体功能，再看连接词在从句内部承担什么成分。
4. 遇到非谓语，先确认它没有谓语资格，再判断它的整体功能，并尝试还原成从句。
5. 如果概念解释不够稳，再查《文法俱乐部》对应章节。

## 内容进入规则

| 内容类型 | 放在哪里 | 说明 |
| --- | --- | --- |
| Larry 视频主讲内容 | `source/full-summary.md` 和对应专题文件 | 这是项目正文，后续可同步到 HTML。 |
| 文法俱乐部章节对应关系 | `source/grammar-club-crosswalk.md` | 只写对照和旁注方向，不替换 Larry 主线。 |
| 术语差异 | `source/terminology-map.md` | 避免“主词/主语”“受词/宾语”等术语混乱。 |
| 经济学人句子分析流程 | `source/economist-analysis-protocol.md` | 供 Codex 对话分析使用，不做网页模块。 |
| 经济学人原文 | 不整篇保存 | 只保存必要句子、出处链接和自己的分析，避免资料库臃肿。 |

## 冲突处理

如果 Larry 和《文法俱乐部》的讲法顺序不同：

- HTML 和主讲义仍按 Larry 主线组织。
- 在旁注里说明《文法俱乐部》的对应章节和补充角度。
- 不把“顺序不同”视为理论冲突。

如果术语不同：

- 项目正文统一使用大陆常见术语：主语、宾语、从句、短语、介词、不定式。
- 文法俱乐部术语保留在术语对照表中。

如果判断口径不同：

- 先以项目当前判断流程为准。
- 把差异记录为“旁注”，等同类句子出现多次后再决定是否修改主线。
