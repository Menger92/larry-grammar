# Larry 语法体系总览

来源说明：本章依据 V01 用户截图整理，负责建立名词性、形容词性、副词性和非谓语的功能颜色入口。

## 本章结论卡

| 项目 | 结论 |
| --- | --- |
| 一句话本质 | 英语长句先按句中功能拆解，再判断每个功能由单词、短语、从句还是非谓语承担。 |
| 核心公式 | `找谓语 → 定主干 → 判功能 → 辨形式 → 处理表达细节` |
| 判断入口 | 先问“这一整块在句中做什么”，不要先被表面形式带走。 |
| 代表判断 | 占名词位置看红色；修饰名词看黄色；修饰动作、状态或整句看绿色；有动词含义但不是谓语看紫色。 |
| 最易混点 | 句中功能和表现形式不是一回事：从句、非谓语和介词短语都可能承担相同功能。 |

## 核心本质

本项目的核心不是把英语拆成一堆术语，而是先判断一个结构进入句子后承担什么功能。功能先行，形式随后：红色对应名词性，黄色对应形容词性，绿色对应副词性，紫色对应非谓语形式。

## 判断步骤

| 步骤 | 判断问题 | 结果 |
| --- | --- | --- |
| 1 | 先找主干谓语和基本句型 | 确定句子骨架。 |
| 2 | 判断每个扩展结构的功能 | 名词性、形容词性、副词性或补语。 |
| 3 | 再看它的表现形式 | 词、短语、从句、非谓语。 |
| 4 | 用颜色回标功能 | 红名词性、黄形容词性、绿副词性、紫非谓语。 |
| 5 | 进入对应章节核对细节 | 避免只按形式猜功能。 |

## 类型速查表

| 功能 | 颜色 | 常见表现形式 | 查找入口 |
| --- | --- | --- | --- |
| 名词性 | 红色 | 名词、名词短语、名词性从句、动名词、不定式 | 名词性从句 / 非谓语 |
| 形容词性 | 黄色 | 形容词、定语、定语从句、分词、不定式、介词短语 | 形容词性从句 / 非谓语 / 介词 |
| 副词性 | 绿色 | 副词、状语、状语从句、分词、不定式、介词短语 | 副词性从句 / 非谓语 / 介词 |
| 非谓语形式 | 紫色 | to do、doing、done | 非谓语 |

## 具体类型：功能颜色

颜色不是按词面分类，而是按句中功能标记。

| 颜色 | 对应功能 | 记忆锚点 |
| --- | --- | --- |
| 红色 | 名词性成分 | 当名词用：主语、宾语、名词性表语/主语补语、同位语 |
| 黄色 | 形容词性成分 | 修饰名词，回答“哪一个 / 什么样的” |
| 绿色 | 副词性成分 | 修饰动作、状态、形容词、副词或整句 |
| 紫色 | 非谓语形式 | 有动作含义，但不承担核心谓语资格 |

## 全局判断流程

```text
1. 找有限谓语
2. 定主句主干和基本句型
3. 剥离定语、状语、补语等扩展
4. 判断扩展部分的整体功能
5. 再判断它是从句、非谓语、介词短语还是单词
6. 最后处理时态、虚拟语气、冠词等表达细节
```

在《经济学人》长句中也按这个顺序进行：先保证主干成立，再解释复杂结构和中文意思。

## 功能与表现形式入口

同一种功能可以由单词、短语、从句或非谓语等不同形式承担。完整的横向对照见[从句总览：功能 × 表现形式矩阵](#clause-overview)；本章只保留“先判功能，再辨形式”的总原则。

## 学习路线

1. 先掌握功能颜色和全局判断流程。
2. 用修饰对象区分形容词性与副词性功能。
3. 用简单句确定谓语、主干和五大句型。
4. 学习从句：完整句子降级后进入另一句。
5. 学习非谓语：动作失去谓语资格后进入其他功能。
6. 学习介词短语：先看介词后的名词性成分，再看整体功能。
7. 最后处理时态、虚拟语气、冠词和词法细节。

## 易混对比

| 易混点 | 判断法 |
| --- | --- |
| 功能和形式混淆 | 先问在句中干什么，再问长什么样。 |
| 从句和非谓语混淆 | 有完整主谓和连接词，优先看从句；没有核心谓语资格，再看非谓语。 |
| 介词短语功能混淆 | 介词短语进入句子后通常走形容词性或副词性路线。 |

## 经济学人分析提示

经济学人中怎么识别：先划主干，再把长修饰、插入语、从句和非谓语逐一标成名词性、形容词性、副词性或非谓语形式，不要被长度吓住。
