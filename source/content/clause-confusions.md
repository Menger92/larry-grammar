# 从句易混对比

## 本章结论卡

| 项目 | 结论 |
| --- | --- |
| 一句话本质 | 易混从句不能靠连接词名称判断，要同时检查整体功能和内部缺项。 |
| 核心公式 | `先判从句整体功能 → 再看连接词内部成分 → 最后比较候选结构` |
| 判断入口 | 先问从句是在占位置、修饰名词，还是修饰主句。 |
| 代表对比 | `that` 只连接时，从句内部完整；`what` 通常还在从句中作成分。 |
| 最易混点 | 同一个 where、when、that 可以进入不同类型的从句。 |

## 核心易混表

| 对比项 | A | B | 判断核心 |
| --- | --- | --- | --- |
| that vs what | that 在名词性从句中只连接，不作成分 | what 在名词性从句里作主语、宾语或表语 | 看从句是否缺名词性成分。 |
| whether vs if | whether 位置更自由，更正式 | if 多用于宾语从句 | 主语从句、介词后、不定式前优先 whether。 |
| 同位语从句 vs 定语从句 | 解释抽象名词的内容 | 修饰限定名词范围 | 看从句是回答“内容是什么”，还是“哪一个”。 |
| which vs where | which 代替名词性成分 | where 代替地点状语 | 看从句缺主语 / 宾语，还是缺地点状语。 |
| 限制性 vs 非限制性定语从句 | 筛选先行词 | 补充额外信息 | 看删除后先行词是否仍然明确，并检查逗号。 |
| 状语从句 vs 定语从句 | 直接修饰动作、状态或主句 | 跟在先行词后修饰名词 | 先看连接词前有没有被修饰的名词。 |

## 长句判断顺序

1. 找出所有有限谓语，先确定主句谓语。
2. 标出连接词，并划清每个从句边界。
3. 判断从句整体在主句中的功能。
4. 检查连接词在从句内部是否作成分。
5. 只有出现两个合理候选时，再回到本章的对比表。

## 易混例句入口

具体例句放在对应专题中：

- `that / what`、`whether / if`、同位语从句：见[名词性从句](#noun-clause)。
- `which / where`、限制性 / 非限制性：见[形容词性从句](#adjective-clause)。
- `where / when` 修饰主句的情况：见[副词性从句](#adverbial-clause)。
