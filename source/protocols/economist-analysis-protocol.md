# 经济学人句子分析协议

本文件用于规范 Codex 对话框里的语法分析输出。HTML 继续作为语法体系学习页；经济学人实战分析直接在对话框完成，不做网页工作台。

## 使用目标

本协议服务于一个核心目标：用《经济学人》的真实句子训练语法判断能力，而不是只得到一句中文翻译。

每次分析都要尽量完成四件事：

1. 找出句子主干。
2. 判断各层结构的句中功能。
3. 说明判断依据和易混点。
4. 把本句转化为下次可复用的判断问题。

## 分析依据

1. 以 Larry 当前语法体系为主线。
2. 以《文法俱乐部》作为理论底座和旁注来源。
3. 遇到无法判断的结构，先回到项目判断流程，而不是直接翻译。

## 输入建议

用户贴《经济学人》句子时，最好提供：

| 信息 | 是否必须 | 用途 |
| --- | --- | --- |
| 原句 | 必须 | 分析对象。 |
| 上下文前后句 | 可选 | 判断指代、省略、转折、因果和语气。 |
| 文章标题 / 日期 / 链接 | 可选 | 后续沉淀案例时使用。 |
| 自己的初步判断 | 推荐 | 用来定位真正卡住的语法点。 |
| 想重点分析的结构 | 可选 | 例如只问非谓语、从句、补语、时态等。 |

## 默认分析顺序

```text
找谓语 -> 定主干 -> 判断基本句型 -> 剥离定语/状语/补语
-> 判断从句 -> 判断非谓语 -> 处理易混点 -> 顺译
```

## 对话标记规则

对话框不能像 HTML 一样稳定显示颜色，所以用文本标签替代颜色：

| 标签 | 对应功能 / 形式 | HTML 标记 |
| --- | --- | --- |
| [名] | 名词性成分：主语、宾语、名词性表语/主语补语、同位语等 | 红色 |
| [形] | 形容词性成分：定语、修饰名词的结构 | 黄色 |
| [副] | 副词性成分：状语、修饰动作/状态/整句的结构 | 绿色 |
| [非] | 非谓语：to do / doing / done 等动词降级形式；属于形式标签，必须和功能分开判断 | 紫色线标 / 角标 |
| [谓] | 句子真正谓语 | 中性标记 |
| [补] | 主语补语 / 宾语补语 | 功能说明 |
| [插] | 插入语、补充说明、破折号结构 | 结构说明 |
| [并] | 并列结构 | 结构说明 |

示例：

```text
[名 The policy] [谓 has made] [名 investors] [补 nervous]
```

红、黄、绿是功能标签；紫色 `[非]` 是形式标签。非谓语片段必须优先叠加说明：

```text
[副][非 Having failed to persuade voters], the party changed its message.
```

## 无法判断时的处理

如果句子结构存在歧义，或缺少上下文，不能强行给唯一答案。按下面格式输出：

```text
不确定点：
- 卡住的片段：
- 为什么不确定：

候选判断：
| 候选 | 可能依据 | 风险 |

需要上下文：
- 指代对象：
- 前后句逻辑：
- 标点或省略信息：

暂定结论：
- 在当前句子内，优先按：
- 但如果上下文显示……，则应改判为：

回看章节：
- 项目章节：
- 文法俱乐部旁注：
```

原则：无法判断时，先说明不确定性，再给暂定结论；不要为了流畅翻译而掩盖语法判断风险。

## 常见优先检查点

经济学人句子中高频卡点：

| 卡点 | 先检查什么 | 项目依据 |
| --- | --- | --- |
| 主句太长 | 先找真正谓语，剥离插入语、介词短语、从句 | 简单句主干判断 |
| 长主语 / 长宾语 | 看是否由从句、非谓语、介词短语或同位语扩展而成 | 功能 × 表现形式矩阵 |
| 状语从句 | 先找它修饰主句中的哪个元素，再判断时间、原因、条件等关系 | 副词性从句修饰对象判断 |
| 时间状语从句 | 区分时间点、时间段、同步变化、持续边界 | when / while / as / until 判断 |
| 原因状语从句 | 检查 because 是否被否定范围影响，because of 后是否只是名词短语 | 原因状语从句判断 |
| 目的 vs 结果 | 看 so that 后是目标可能性，还是已经发生的结果 | 目的/结果状语从句判断 |
| 条件状语从句 | 区分 if 条件和 in case 预防；unless = if...not | 条件状语从句判断 |
| 让步状语从句 | 看从句成立后主句是否仍成立，注意 although 不和 but 连用 | 让步状语从句判断 |
| 比较状语从句 | 先补出省略，再看比较对象是否对齐 | 比较状语从句判断 |
| which / that / where | 看前面有没有先行词，再看从句内部缺什么 | 定语从句判断 |
| what / that / whether | 看整个从句是否占名词位置，再看连接词是否在从句内部承担成分 | 名词性从句判断 |
| doing / done | 看它有没有谓语资格，再判断逻辑主语和主被动 | 非谓语判断 |
| to do | 看它整体作名词、定语、状语还是补语 | 不定式判断 |
| 介词短语 | 看整体修饰名词、动作、形容词还是整句 | 介词短语功能判断 |
| 补语 vs 状语 | 先做 [A is / becomes B] 或逻辑主谓检验，再检查 B 是补充 A 还是修饰动作 | 补语判断表 |
| 必需补语 vs 次级谓语 | 删除后检查原义/句型是否完整；可删除不等于状语 | 补语判断表 |
| 插入语 | 先临时拿掉，看主干是否恢复完整 | 简单句主干判断 |
| 破折号 / 冒号 | 判断后面是在解释、补充、举例还是转折 | 同位语 / 插入语 / 补充说明 |
| 分号 | 判断两边是否都是完整分句，以及逻辑关系是什么 | 并列分句 |
| 并列结构 | 检查并列对象是否同层级、同功能、同形式 | 词性与句子功能对齐 |
| 省略 | 补出被省略的主语、谓语、比较对象或连接词 | 比较状语从句 / 并列结构 |
| 同位语 | 看后面是不是解释前面名词的内容或身份 | 名词性功能 / 同位语从句 |
| 名词化 | 把抽象名词还原成动作或从句理解 | 名词性成分 |
| 被动结构 | 找动作承受者和可能省略的施事者 | 谓语判断 / 非谓语 done |
| 引语 / 转述 | 区分报道动词、that 从句、直接引语边界 | 名词性从句 |
| 新闻标题省略 | 检查冠词、be 动词、助动词是否省略 | 词法解析 / 简单句 |

## 每次分析后的学习闭环

每次分析结束时，默认给一个短学习卡片。长难句或用户明显卡住时，学习卡片必须包含：

```text
学习卡片
- 本句最核心结构：
- 我以后先问自己的 3 个问题：
- 对应项目章节：
- 是否值得加入例句库：
```

“3 个问题”优先写成可操作的判断问题，例如：

1. 这个结构整体在句中当什么？
2. 它修饰谁，还是补充说明谁？
3. 它能不能还原成从句或小分句？

## 输出质量检查

每次输出前自检：

1. 有没有先找主干，而不是直接翻译？
2. 每个重点片段有没有说明句中功能？
3. 从句和非谓语有没有区分“内部结构”和“整体功能”？
4. 易混点有没有给检验方式？
5. 顺译是否建立在语法判断之后？
6. 学习卡片是否能帮助下次独立判断？

## 项目维护说明

以下内容只用于后续沉淀和维护，不影响每次对话分析的阅读顺序。

### 经济学人材料保存原则

不把整篇文章保存进项目。后续如果要沉淀案例，只保存：

- 文章标题、日期、链接。
- 必要的单句或短片段。
- 自己的语法分析和学习卡片。
- 卡住的判断点。

推荐沉淀格式：

```text
文章：
日期：
链接：
句子：
卡点：
最终判断：
项目依据：
学习卡片：
```

### 回填语法库的触发条件

如果同类卡点在经济学人分析中反复出现三次以上，就考虑回填到项目正文：

1. 新增易混表。
2. 补充例句库。
3. 在对应模块加入《文法俱乐部》旁注。
4. 必要时同步到 HTML 学习页。

### 回填等级

| 等级 | 条件 | 处理 |
| --- | --- | --- |
| 观察 | 第一次遇到，且判断已经清楚 | 只在对话中给学习卡片。 |
| 记录 | 第二次遇到同类卡点，或用户明显卡住 | 记录到待回填清单或复盘材料。 |
| 回填 | 第三次以上反复出现，或能代表一个高频结构 | 写入对应章节的易混表、例句库或关联学习。 |
| 旁注 | Larry 主线能判断，但理论解释不够稳 | 补《文法俱乐部》旁注和术语对照。 |
