# 经济学人句子分析协议

本文件用于规范 Codex 对话框里的语法分析输出。HTML 继续作为语法体系学习页；经济学人实战分析直接在对话框完成，不做网页工作台。

## 分析依据

1. 以 Larry 当前语法体系为主线。
2. 以《文法俱乐部》作为理论底座和旁注来源。
3. 遇到无法判断的结构，先回到项目判断流程，而不是直接翻译。

## 默认分析顺序

```text
找谓语 -> 定主干 -> 判断基本句型 -> 剥离定语/状语/补语
-> 判断从句 -> 判断非谓语 -> 处理易混点 -> 顺译
```

## 经济学人材料保存原则

不把整篇文章保存进项目。后续如果要沉淀案例，只保存：

- 文章标题、日期、链接。
- 必要的单句或短片段。
- 自己的语法分析和学习卡片。
- 卡住的判断点。

## 常见优先检查点

经济学人句子中高频卡点：

| 卡点 | 先检查什么 | 项目依据 |
| --- | --- | --- |
| 主句太长 | 先找真正谓语，剥离插入语、介词短语、从句 | 简单句主干判断 |
| 状语从句 | 先找它修饰主句中的哪个元素，再判断时间、原因、条件等关系 | 副词性从句修饰对象判断 |
| 时间状语从句 | 区分时间点、时间段、同步变化、持续边界 | when / while / as / until 判断 |
| 原因状语从句 | 检查 because 是否被否定范围影响，because of 后是否只是名词短语 | 原因状语从句判断 |
| 目的 vs 结果 | 看 so that 后是目标可能性，还是已经发生的结果 | 目的/结果状语从句判断 |
| 条件状语从句 | 区分 if 条件和 in case 预防；unless = if...not | 条件状语从句判断 |
| 让步状语从句 | 看从句成立后主句是否仍成立，注意 although 不和 but 连用 | 让步状语从句判断 |
| 比较状语从句 | 先补出省略，再看比较对象是否对齐 | 比较状语从句判断 |
| which / that / where | 看前面有没有先行词，再看从句内部缺什么 | 定语从句判断 |
| what / that / whether | 看整个从句是否占名词位置，再看连接词是否在从句内部承担成分 | 名词性从句判断 |
| doing / done | 看它有没有谓语资格，再判断逻辑主语和主被动 | 非谓语判断 |
| to do | 看它整体作名词、定语、状语还是补语 | 不定式判断 |
| 介词短语 | 看整体修饰名词、动作、形容词还是整句 | 介词短语功能判断 |
| 补语 vs 状语 | 做 [A is B] 小分句检验 | 补语判断表 |

## 回填语法库的触发条件

如果同类卡点在经济学人分析中反复出现三次以上，就考虑回填到项目正文：

1. 新增易混表。
2. 补充例句库。
3. 在对应模块加入《文法俱乐部》旁注。
4. 必要时同步到 HTML 学习页。
