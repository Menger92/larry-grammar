# 术语对照表

本项目正文统一使用大陆常见语法术语；阅读《文法俱乐部》时，遇到港台术语按本表转换。

## 核心术语

| 项目统一术语 | 文法俱乐部常见术语 | 英文 | 说明 |
| --- | --- | --- | --- |
| 主语 | 主词 | Subject | 句子的主体话题或动作发出者。 |
| 谓语 / 谓语动词 | 动词 / 述部 | Predicate / Verb | 项目分析时优先找核心谓语动词。 |
| 宾语 | 受词 | Object | 动作影响或指向的对象。 |
| 补语 | 补语 | Complement | 补足主语或宾语的状态、身份、结果。 |
| 主语补语 | 主词补语 | Subject Complement | 传统“表语”在本项目中归入主语补语。 |
| 宾语补语 | 受词补语 | Object Complement | 用 [A is / becomes B] 或逻辑主谓关系作初步检验，再检查动词选择关系。 |
| 次级谓语 | 次述语 / 描写性补语 | Secondary Predicate | 对主语或宾语再次作出状态描写；可能是可选成分，不能只靠删除测试判断。 |
| 表语 | 主词补语 / 补语 | Predicative | 本项目中表语属于主语补语。 |
| 从句 | 子句 | Clause | 依附于更大结构的小句；本项目重点分析有自身有限谓语的从属小句。 |
| 名词性从句 | 名词子句 | Noun Clause | 整体当名词用。 |
| 定语从句 / 形容词性从句 | 关系子句 / 形容词子句 | Relative / Adjective Clause | 整体修饰名词。 |
| 状语从句 / 副词性从句 | 副词子句 | Adverbial Clause | 整体修饰动作、状态或主句。 |
| 短语 | 片语 | Phrase | 没有完整主谓结构的词组。 |
| 名词短语 | 名词片语 | Noun Phrase | 以名词为核心的短语。 |
| 介词 | 介系词 | Preposition | 后面接名词性成分，构成介词短语。 |
| 不定式 | 不定词 | Infinitive | to do 或省略 to 的原形动词结构。 |
| 动名词 | 动名词 | Gerund | doing 整体当名词用。 |
| 现在分词 | 现在分词 | Present Participle | doing 作形容词性、副词性或补语。 |
| 过去分词 | 过去分词 | Past Participle | done 常表达被动或完成。 |
| 非谓语 | 非限定动词 / 减化子句结果 | Non-finite Verb | 动词降级，有动作含义但不作核心谓语。 |
| 从句压缩 | 减化子句 | Reduced Clause | 从句省略主语、be 或连接词后形成更短结构。 |
| 并列句 | 合句 | Compound Sentence | 两个或多个同等地位的分句并列。 |
| 复杂句 | 复句 | Complex Sentence | 主句中嵌入从属从句。 |
| 主谓一致 | 主词动词一致性 | Subject-Verb Agreement | 主语和谓语在人称、数上保持一致。 |

## 判断口径

| 容易混乱处 | 本项目口径 |
| --- | --- |
| 表语 vs 主语补语 | 表语不单独作为核心类别；分析时归入主语补语。 |
| 定语从句 vs 形容词性从句 | 两者在本项目中基本等同；强调功能时说形容词性从句，强调传统名称时说定语从句。 |
| 状语从句 vs 副词性从句 | 两者在本项目中基本等同；强调功能时说副词性从句，强调句法位置时说状语从句。 |
| 非谓语 vs 减化子句 | Larry 主线用“非谓语 / 动词降级”理解；文法俱乐部常从“减化子句”角度解释。两者可互相验证。 |
| 宾补 vs 状语 | 用 [宾语 + 后面成分] 是否能构成语义自洽小分句来检验。 |

## 使用方式

阅读《文法俱乐部》时，先把术语翻译成项目统一术语，再放回 Larry 判断流程：

```text
主词 -> 主语
受词 -> 宾语
子句 -> 从句
片语 -> 短语
介系词 -> 介词
不定词 -> 不定式
减化子句 -> 从句压缩 / 非谓语化
```
