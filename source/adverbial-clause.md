# 副词性从句

## 3.7 副词性从句 / 状语从句

副词性从句的核心：整个从句作状语，说明主句动作或主句整体的逻辑关系。

### 3.7.1 状语从句复习入口

副词性从句不要先背连接词，先问它回答了什么问题。

| 判断问题 | 对应类型 | 常见连接词 |
| --- | --- | --- |
| 什么时候？到什么时候？一……就……？ | 时间状语从句 | when, while, before, after, until, not until, as soon as, immediately, the moment, the minute, the second |
| 在哪里？无论在哪里？ | 地点状语从句 | where, wherever |
| 为什么？由于什么原因？ | 原因状语从句 | because, since, as, for |
| 在什么条件下？ | 条件状语从句 | if, unless, as long as, so long as, provided that |
| 虽然怎样？即使怎样？无论怎样？ | 让步状语从句 | although, though, even if, even though, while, no matter + 疑问词 |
| 为了什么？ | 目的状语从句 | so that, in order that |
| 结果怎样？ | 结果状语从句 | so...that, such...that |
| 和谁比？程度如何？ | 比较状语从句 | than, as...as, not as/so...as |
| 像什么一样？仿佛怎样？ | 方式状语从句 | as, as if, as though |

### 3.7.2 时间状语从句补充

时间状语从句里，重点不是只认识 when，而是区分“动作发生的时间关系”。

| 结构 | 记忆点 | 笔记例句 |
| --- | --- | --- |
| until | 主句动作一直持续到从句时间点。 | 待补充截图例句 |
| not until | 主句动作直到从句时间点才发生。 | We didn't go out until it stopped raining. |
| It was not until...that... | not until 的强调句结构。 | It was not until it stopped raining that we went out. |
| as soon as | 一……就……。 | It began to rain as soon as we arrived home. |
| the moment / minute / second | 名词短语也可引导“一……就……”的时间关系。 | 待补充截图例句 |
| no sooner...than / hardly...when | 倒装形式，表达“刚……就……”。 | No sooner had we arrived home than it began to rain. |

### 3.7.3 原因、目的、结果的区别

这三类最容易混在一起。判断时不要只看连接词，要看主句和从句之间的逻辑方向。

| 类型 | 逻辑方向 | 典型标记 | 判断方式 |
| --- | --- | --- | --- |
| 原因 | 因为 A，所以 B | because, since, as, for | 从句解释主句为什么发生。 |
| 目的 | 为了 A，所以做 B | so that, in order that | 从句说明主句动作想达到的目标。 |
| 结果 | B 造成 A | so...that, such...that | 从句说明主句程度或情况导致的结果。 |

### 3.7.4 让步状语从句补充

让步状语从句表达“虽然从句成立，但主句仍然成立”。学习时重点看转折关系，而不是把 every word 都翻译成“虽然”。

| 结构 | 记忆点 |
| --- | --- |
| although / though | 常规让步。 |
| even if / even though | 让步语气更强。 |
| while | 可表示对比或让步，具体看上下文。 |
| no matter + 疑问词 | 无论谁、无论哪里、无论怎样。 |

### 3.7.5 地点状语从句补充

where 不一定都是定语从句。判断关键是：前面有没有被修饰的地点名词。

| 类型 | 判断点 | 例句 |
| --- | --- | --- |
| 地点状语从句 | where 从句直接修饰动作，没有先行词。 | Where there is a will, there is a way. |
| 定语从句 | where 前面有地点名词，where 从句修饰这个名词。 | 见形容词性从句章节。 |

记忆点：`where` 可以是副词性从句连接词，也可以是定语从句关系副词。先看它前面有没有名词，再判断它在句中承担什么功能。
