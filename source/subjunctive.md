## 1. 虚拟语气入口

来源视频：V24｜BV1X2421N7L1｜虚拟语气（1）

视频简介中的核心定位：

```text
虚拟语气并不是“语法”这个知识框架的某一个组成部分，
而是在“语法”的基础上，叠加了一个额外的虚拟维度。
```

### 1.1 为什么难

| 难点 | Larry 讲法 | 学习处理 |
| --- | --- | --- |
| 情态动词 | would / could / might / should 本身带态度 | 不要只按“将来 / 过去”翻译。 |
| 虚拟语气 | 句子进入非现实、假设、愿望或强烈主观意愿空间 | 先判断真实条件还是非真实条件。 |
| 时态 | 过去形式常常不是过去时间，而是心理距离 | 时间关系和虚拟关系分开看。 |
| 负迁移 | 中文没有同样强的形式标记 | 不能只靠中文意思判断。 |

学习顺序：

1. 先理解虚拟语气的本质：为什么虚拟，能不能不虚拟，虚拟与不虚拟有什么意义差别。
2. 再把虚拟语气的语法规则烂熟于心。
3. 真实条件句和非真实条件句认真对比。
4. 记住：虚拟语气都有言外之意。

### 1.2 真实条件句 VS 非真实条件句

代表例句：If I could help you, I would definitely do so.

| 类型 | 例句 | 判断 |
| --- | --- | --- |
| 真实条件句 | If I can help you, I will definitely do so. | 说话人把条件当作可能发生的现实条件。 |
| 非真实条件句 | If I could help you, I would definitely do so. | 说话人把条件放进虚拟空间，言外之意通常是“我现在帮不了你”。 |

### 1.3 三时态虚拟规则总表

这个表是 V24-V26 反复出现的核心表。学习时先问“虚拟的对象是过去、现在还是将来”，再套主句和 if 从句形式。

| 虚拟的对象 | 主句的谓语形式 | if 从句的谓语形式 |
| --- | --- | --- |
| 将来 | would / could / might / should + do | were to do / should 或 could do / did |
| 现在 | would / could / might / should + do | did / were |
| 过去 | would / could / might / should + have done | had done / had been |

记忆点：

- 主句用情态动词过去式，是为了表达距离感，不一定表示过去时间。
- if 从句用过去形式或过去完成形式，是为了把条件推入非现实空间。
- `were` 在虚拟语气里常用于所有人称，书面和正式感更强。

## 2. V24：针对过去、现在、将来的虚拟

### 2.1 狗血故事不是为了剧情，而是为了建立语感

视频用 Michael、Sally、Susan、Jimmy 的连续故事，把虚拟语气放进“真实情况”和“脑内假设”的对比里。学习重点不是记住剧情，而是看每一句虚拟背后的言外之意。

| 人物 | 故事功能 |
| --- | --- |
| Michael | 多数虚拟句的说话人之一，经常在现实和后悔中切换。 |
| Sally | 与 Michael 的关系推动“如果当初 / 如果现在 / 如果将来”的假设。 |
| Susan | 引出过去事实已定、现在后悔、将来假设等多种虚拟。 |
| Jimmy / Max | 引出交叉时态和含蓄条件。 |

### 2.2 将来假设

代表例句：If Apple wanted me, I would consider it.

| 类型 | 例句 | 判断 |
| --- | --- | --- |
| 将来低可能假设 | If Apple wanted me, I would consider it. | 用过去式 wanted 把“Apple 要我”放进低可能假设。 |
| 真实将来条件 | If Tencent offers me a job, I might just take it. | offers 是真实条件，不是虚拟。 |
| 将来虚拟条件 | If Tencent offered me a job, I might just take it. | offered 把条件推远，表示低可能或不确定。 |

### 2.3 现在假设

代表例句：If we had five million, we could buy a house outright.

| 例句 | 判断 |
| --- | --- |
| If we had five million, we could buy a house outright. | 现在事实是没有五百万。 |
| If Tencent would hire me, I'd be over the moon. | 把 Tencent 愿意录用放进虚拟空间。 |
| If he were your son, how come he's five years old and hasn't seen you as a dad? | 用 were 表示与现实身份不一致的假设。 |

### 2.4 过去假设

代表例句：If I had known Apple was your family's company, I wouldn't have taken this job in the first place.

| 例句 | 判断 |
| --- | --- |
| If I had known Apple was your family's company, I wouldn't have taken this job in the first place. | 过去事实是“我不知道”。 |
| If my dad was a regular farmer like Sally's, would you fancy me? | 对身份 / 背景作非现实假设。 |
| If my dad had never divorced Apple's boss, I could be the heir to the richest company in the world. | 过去事实改变，推出现实身份改变。 |

## 3. V25：倒装结构虚拟句

来源视频：V25｜BV1dm411R7uG｜虚拟语气（2）

### 3.1 倒装规则

从句倒装的规则：省略 `if`，然后把条件句中的 `were / had / could / should` 放在主语之前。

代表例句：Had I known you were like this, I would have taken Tencent's offer today.

| 普通 if 从句 | 倒装形式 | 判断 |
| --- | --- | --- |
| If I had known you were like this, I would have taken Tencent's offer today. | Had I known you were like this, I would have taken Tencent's offer today. | 省略 if，had 前置。 |
| If my dad were a regular farmer like Sally's, would you fancy me? | Were my dad a regular farmer like Sally's, would you fancy me? | 省略 if，were 前置。 |
| If I were you, I should've sealed the deal with Michael from the get-go. | Were I you, I should've sealed the deal with Michael from the get-go. | `Were I you` 是常见书面虚拟倒装。 |

<summary>对比例句库：倒装结构的可用与不可用</summary>

| 例句 | 判断 |
| --- | --- |
| If my dad was a regular farmer like Sally's, would you fancy me? | 口语里可见 was。 |
| If my dad were a regular farmer like Sally's, would you fancy me? | 虚拟语气中 were 更标准。 |
| Were my dad a regular farmer like Sally's, would you fancy me? | 可倒装。 |
| Even if Apple wasn't in the mix, I still wouldn't be into you, Susan. | 有 even if，不适合直接倒装成 even were。 |
| If you loved me, you wouldn't have lied to me. | `loved` 不能直接前置倒装。 |
| Even if I had told you the truth, would you believe me? | even if 不直接倒装。 |
| Hadn't we orchestrated this little drama, there wouldn't be any chance for Sally to fall into my lap. | had 前置倒装。 |
| If my family wasn't so loaded, could I still have a chance with her? | 口语式 was / wasn't。 |
| If my family weren't so loaded, could I still have a chance with her? | 虚拟式 were / weren't。 |
| Were my family not so loaded, could I still have a chance with her? | 书面倒装。 |
| Weren't my family so loaded, could I still have a chance with her? | 截图标注为罕见 / 不常用。 |
| If we were to tie the knot, we would both have our freedom. | were to do 表将来假设。 |
| Were we to tie the knot, we would both have our freedom. | were 前置倒装。 |
| If I hadn't made such unforgivable mistake back then, you wouldn't have suffered so much. | 普通 if 从句。 |
| Had I not made such unforgivable mistake back then, you wouldn't have suffered so much. | had 前置倒装。 |
| Hadn't I made such unforgivable mistake back then, you wouldn't have suffered so much. | 截图标注为罕见 / 不常用。 |

## 4. V25：交叉时态虚拟句

交叉时态虚拟句的核心是：if 从句虚拟的时间和主句虚拟的时间不一致。不要机械套“过去配过去、现在配现在”，要看每一部分实际指向哪个时间。

### 4.1 从句过去虚拟 + 主句现在虚拟

代表例句：If my mom hadn't divorced him back then, I'd be cruising in a Bugatti by now.

| 例句 | 判断 |
| --- | --- |
| If my mom hadn't divorced him back then, I'd be cruising in a Bugatti by now. | if 从句说过去事实，主句说现在状态。 |
| If your mom had been the ex-wife of the Tencent boss, my mom would be the grandmother of the Microsoft CEO! | 过去身份假设影响现在身份。 |
| If my dad hadn't divorced the Apple boss back then, I could be the heir to the richest company in the world! | 过去事实改变，主句落到现在。 |

### 4.2 从句现在虚拟 + 主句过去虚拟

代表例句：If I were you, I would've taken those orders just now.

| 例句 | 判断 |
| --- | --- |
| If I were you, I would've taken those orders just now. | if 从句是假设身份，主句说刚才本该做什么。 |
| If you were me, you would've committed suicide a long time ago. | 现在身份假设 + 过去动作判断。 |
| If I were your parent, I would've regretted having a son like you. | 现在身份假设 + 过去心理评价。 |

### 4.3 从句现在虚拟 + 主句将来虚拟

代表例句：Even if I took a hundred more orders, I still wouldn't have food for tomorrow.

| 例句 | 判断 |
| --- | --- |
| If you keep slacking off, you won't even have food for tomorrow. | 真实条件，不是虚拟。 |
| Even if I took a hundred more orders, I still wouldn't have food for tomorrow. | 对现在 / 接下来行为作假设，结果指向明天。 |
| If I were the owner of that BMW, I'd have demanded a grand from you. | 身份假设影响之后可能采取的行动。 |

### 4.4 从句过去虚拟 + 主句将来 / 现在虚拟

代表例句：If you hadn't broken up with the boss of Apple, I wouldn't have to wake up to be a delivery guy tomorrow.

| 例句 | 判断 |
| --- | --- |
| If you hadn't divorced the boss of Tencent back then, I wouldn't be in this mess today! | 过去事实改变，今天状态不同。 |
| If you hadn't broken up with the boss of Apple, I wouldn't have to wake up to be a delivery guy tomorrow! | 过去事实改变，明天结果不同。 |
| If we had chosen money back then, we wouldn't have the happy life we have now, nor could we expect a better future. | 过去选择影响现在和未来。 |

## 5. V25：无条件虚拟句

无条件虚拟句不再使用 if 从句形式，而是用非谓语、介词短语、状语、主语等其他形式表达类似虚拟意义。

代表例句：Given another chance, I would still divorce Susan to marry Sally.

| 形式 | 例句 | 隐含条件 |
| --- | --- | --- |
| if 从句 | If I had another chance, I would still divorce Susan to marry Sally. | 如果再有一次机会。 |
| 分词 / 介词化结构 | Given another chance, I would still divorce Susan to marry Sally. | given another chance = if I were given another chance。 |
| 名词性成分 | Any wise man would still divorce Susan to marry Sally. | 任何明智的人在这种情况下都会这样做。 |
| 形容词 / 不定式结构 | A man would be blind not to have divorced Susan to marry Sally. | 如果没这么做，就很盲目。 |
| 不定式作主语 | Not to divorce Susan to marry Sally would be the silliest thing to do. | 不这么做会是最蠢的事。 |
| 完成不定式 | To have divorced Susan earlier, I would have married Sally sooner for a better life. | 如果早些离婚。 |
| only that | I would have spent the rest of my life with Susan, only (that) I fell in love with Sally again. | 要不是后来又爱上 Sally。 |

## 6. V25：含蓄条件句

含蓄条件句完全省略 if 从句，也不一定存在任何非条件成分；虚拟意思依赖上下文或读者自行脑补。

代表例句：If only we had five million! We could buy a house outright.

| 类型 | 例句 | 判断 |
| --- | --- | --- |
| 含蓄条件 | If only we had five million! We could buy a house outright. | 条件不再是完整 if 从句，靠感叹引出虚拟。 |
| 含蓄结果 | If only my dad hadn't divorced the boss of Apple! | 只表达愿望或后悔，结果靠上下文理解。 |
| 语境脑补 | If my dad was a regular farmer like Sally's, would you fancy me? | 真实含义依赖上下文中的身份和财富设定。 |

## 7. V26：名词性从句中的虚拟语气（表示意愿）

来源视频：V26｜BV12K421a7Bb｜虚拟语气（3）

核心：如果名词性从句中含有特定的“强烈主观意愿”标志词，从句谓语动词常用原形；英式英语中也常见 `should + 动词原形`。

### 7.1 标志动词

截图标志词：

```text
ask, advise, command, beg, request, suggest, demand, decide,
deserve, desire, insist, order, prefer, propose, urge
```

代表例句：Michael insisted that this marriage be ended as soon as possible.

| 例句 | 判断 |
| --- | --- |
| Michael insisted that this marriage be ended as soon as possible. | insist 表强烈主观意愿，that 从句用 be ended。 |
| Jimmy demanded that Sally not be allowed to take any property. | demand 表要求，从句用 not be allowed。 |
| Sally suggested that they start a new life in the slums. | suggest 表建议，从句用 start。 |
| Max asked that his father divorce Sally to remarry Susan. | ask 表请求，从句用 divorce。 |

### 7.2 必须区分标志词是否真的表达意愿

代表例句：Sally suggested that they start a new life in the slums.

| 例句 | 判断 |
| --- | --- |
| Sally suggested that they start a new life in the slums given their dire financial situation. | suggest = 建议，用虚拟。 |
| Sally's unusual behavior suggested that she had been pregnant with Michael's child for quite some time. | suggest = 表明 / 暗示，不用虚拟。 |
| Michael insisted that this marriage be ended as soon as possible. | insist = 坚持要求，用虚拟。 |
| Susan insisted that it was Michael who was at fault. | insist = 坚称事实，不用虚拟。 |

### 7.3 标志动词的各种变体

代表例句：It is advisable that Sally take no property.

| 结构 | 例句 |
| --- | --- |
| 动词 | The attorney advised that Sally take no property because she was at fault for getting pregnant with Michael's child. |
| 形容词 | It is advisable that Sally take no property because she was at fault for getting pregnant with Michael's child. |
| 形式宾语 | The attorney thought it advisable that Sally take no property because she was at fault for getting pregnant with Michael's child. |
| 表语从句 | What is advisable is that Sally take no property because she was at fault for getting pregnant with Michael's child. |
| 被动 | Sally was advised that she take no property because she was at fault for getting pregnant with Michael's child. |
| 同位语 | The advice that Sally take no property because she was at fault for getting pregnant with his child makes a lot of sense. |

### 7.4 It is + adj + that 从句

截图标志词：

```text
important, necessary, advisable, appropriate, desirable,
essential, imperative, normal, surprising, strange, vital
```

代表例句：It is important that Jimmy make sure Sally doesn't take away any property.

| 类型 | 例句 | 判断 |
| --- | --- | --- |
| 强烈意愿 / 必要性 | It is important that Jimmy make sure Sally doesn't take away any property. | important 后的 that 从句用动词原形。 |
| 惊讶 should | It is strange that Michael should divorce Susan, the boss of Apple. | should 保留，表示“竟然”。 |
| 非虚拟事实陈述 | It is natural that people divorce someone they don't love. | 表普遍事实，不按虚拟处理。 |
| 惊讶 should | It is surprising that Jimmy should marry Susan. | should 表“竟然”。 |
| 非虚拟事实陈述 | It is surprising that Jimmy has married Susan. | 陈述已经发生的事实。 |

### 7.5 It is time / about time / high time + that

代表例句：It's time (that) you divorced Susan.

| 结构 | 例句 | 语气 |
| --- | --- | --- |
| It's time | It's time (that) you divorced Susan. | 该做了。 |
| It's about time | It's about time (that) you divorced Susan. | 也该做了。 |
| It's high time | It's high time (that) you divorced Susan. | 早就该做了。 |
| be going | It's time (that) we were going. | 该走了。 |
| about time + be going | It's about time (that) we were going. | 差不多该走了。 |
| high time + be going | It's high time (that) we were going. | 早该走了。 |

不要混淆：

| 结构 | 例句 | 判断 |
| --- | --- | --- |
| It is time that... | It is time (that) we left. | 虚拟语气，表示“该走了”。 |
| It is the first time that... | It is the first time that we've been here. | first time 结构，不是 high time 虚拟。 |
| It was the first time that... | It was the first time that we'd been here. | 用过去完成配合过去参照点。 |
| It will be the first time that... | It will be the first time that we've been here. | 将来参照下的 first time。 |

### 7.6 wish 与 hope

#### wish + 宾语从句

代表例句：I wish (that) my dad had never divorced Apple's boss.

| 虚拟对象 | 例句 |
| --- | --- |
| 过去 | I wish (that) my dad had never divorced Apple's boss. |
| 过去 | I wish (that) my mom had never broken up with Tencent's boss. |
| 现在 | I wish (that) my mom were still the wife of the boss of Tencent. |
| 现在 | I wish (that) my dad were still the CEO of Apple. |
| 将来 | I wish (that) I could have a Bugatti someday. |
| 将来 | I wish (that) my dad would get back together with Apple's boss. |

#### wish 和 hope 的不同

| 判断点 | wish | hope |
| --- | --- | --- |
| 后接不定式 | I wish/hope to marry you soon. | I wish/hope to marry you soon. |
| 后接 for | I wish/hope for the best. | I wish/hope for the best. |
| wish sb to do | I wish my dad to get back together with Apple's boss. | hope sb to do 不成立。 |
| 双宾语 | I wish you a better life. | hope 不这样用。 |
| that 从句 | I wish (that) I could marry you. | I hope (that) I can marry you. |
| 语气 | wish 后 that 从句可用虚拟语气。 | hope 后 that 从句通常用陈述语气。 |

## 8. V26：非主流形式虚拟句

### 8.1 超大型主观意念降临

代表例句：Long live The People's Republic of China!

| 例句 | 判断 |
| --- | --- |
| Long live The People's Republic of China! | 表强烈祝愿。 |
| Heaven help us! | 表祈愿。 |
| Manners be hanged! | 表强烈态度。 |
| Damn you! | 表诅咒 / 强烈情绪。 |

### 8.2 as if / as though / if only / would that

代表例句：It seems as if you were going to divorce Susan.

| 结构 | 例句 | 判断 |
| --- | --- | --- |
| as if | It seems as if you were going to divorce Susan. | were going 表虚拟。 |
| as if 陈述 | It seems as if you are going to divorce Susan. | 说话人把它当现实可能。 |
| as though | It seems as though Michael were going to divorce Susan, but he's just putting on an act. | 与事实有距离。 |
| if only | If only my dad had never divorced Apple's boss! | 表对过去的愿望 / 后悔。 |
| if only | If only I were still the son of a wealthy family! | 表对现在的愿望。 |
| would that | Would that my dad had never divorced Apple's boss! | 更书面 / 文学化的愿望。 |
| would that | Would that I were still the son of a wealthy family! | 对现在身份的愿望。 |

### 8.3 for fear that / lest / in order that / so that / in case

代表例句：Sally dares not tell Michael that he is actually Max's biological parent for fear that he would disrupt their current stable life.

| 连接结构 | 例句 | 判断 |
| --- | --- | --- |
| for fear that | Sally dares not tell Michael that he is actually Max's biological parent for fear that he would disrupt their current stable life. | 害怕某事发生。 |
| lest | Sally dares not tell Michael that he is actually Max's biological parent lest he might disrupt their current stable life. | 以免。 |
| in order that | In order that Michael would not disrupt their current stable life, Sally dares not tell him about Max's parentage. | 为了避免结果。 |
| so that | Sally dares not tell Michael that he is actually Max's biological parent so that he wouldn't disrupt their current stable life. | 表目的 / 避免。 |
| in case | Sally dares not tell Michael that he is actually Max's biological parent in case he would disrupt their current stable life. | 以防。 |

注意 `in case`：

| 例句 | 判断 |
| --- | --- |
| I'll bring an umbrella in case it rains. | 普通预防。 |
| I'll bring an umbrella in case it rained. | 用过去式拉开距离。 |
| I'll bring an umbrella in case it might/should/would rain. | 带情态动词，增加不确定或虚拟色彩。 |

### 8.4 其他类型的虚拟语气

代表例句：I would rather (that) it were winter.

| 结构 | 例句 |
| --- | --- |
| would rather | I would rather (that) it were winter. |
| would rather | My dad is a billionaire. I'd rather (that) he weren't. |
| would prefer | I would prefer (that) you had been available. |
| granted that | Granted that he had been drunk, there is no excuse for him to have done that. |
| had better | You'd better finish your work as soon as possible. |
| suppose that | Suppose that there were no gravitational force, things would not fall to the ground when dropped. |
| unless | I couldn't finish this work unless I were allowed another ten days. |
| be it | Be it so late, I have to finish this work. |
| be that as it may | Be that as it may, Michael is determined to divorce Susan. |
| whether it be | Whether it be sunny or raining, he takes a walk outside everyday. |

## 9. 一页复习卡

| 问题 | 快速判断 |
| --- | --- |
| 虚拟语气的本质是什么？ | 在普通语法上叠加“非现实 / 假设 / 愿望 / 强烈主观意愿”的维度。 |
| 为什么过去式不一定表示过去？ | 过去形式可以制造心理距离。 |
| if 条件句先看什么？ | 先看虚拟对象是将来、现在还是过去。 |
| 主句常用什么形式？ | 将来 / 现在：would/could/might/should + do；过去：would/could/might/should + have done。 |
| if 从句常用什么形式？ | 将来：were to do / should do / did；现在：did / were；过去：had done / had been。 |
| 倒装虚拟怎么来？ | 省略 if，把 were / had / should 等放到主语前。 |
| 交叉时态怎么判断？ | if 从句和主句分别看时间，不强行配对。 |
| 无条件虚拟怎么看？ | 没有 if，但其他结构承担隐含条件。 |
| 含蓄条件怎么看？ | 条件完全靠上下文或读者脑补。 |
| 名词性从句虚拟怎么看？ | 看是否有强烈主观意愿标志词，that 从句多用动词原形。 |
| wish 和 hope 最大区别？ | wish 的 that 从句可虚拟；hope 的 that 从句通常陈述。 |
