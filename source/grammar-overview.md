# Larry 语法体系总览

来源说明：本章依据 V01 用户截图整理，负责建立名词性、形容词性、副词性和非谓语的功能颜色入口。

## 颜色规则对照表

颜色不是按词面分类，而是按句中功能标记。阅读时先看颜色对应的功能，再判断具体形式。

| 颜色 | 对应成分 | 记忆锚点 |
| --- | --- | --- |
| 红色 | 名词性成分 | 当名词用：主语、宾语、表语、同位语 |
| 黄色 | 形容词性成分 | 修饰名词：回答“什么样的” |
| 绿色 | 副词性成分 | 修饰动作、状态、其他副词或整句 |
| 紫色 | 非谓语 / 不定式 | 动词降级，有动作含义但不作谓语 |

## 学习路线

这套体系按真实阅读时的判断顺序整理，不按传统语法书目录平铺。

1. 先建立功能地图：名词性、形容词性、副词性、非谓语。
2. 单独掌握词性之间的修饰关系：先找修饰对象，再判断形容词性或副词性功能。
3. 再掌握简单句主干：主语 + 谓语 + 宾语 + 定语 + 状语 + 补语。
4. 然后处理从句：完整句子被连接词降级后，进入名词性、形容词性或副词性功能。
5. 接着处理非谓语：动词降级后，承担名词性、形容词性或副词性功能。
6. 再看介词短语：介词 + 名词性成分后，整体进入形容词性或副词性功能。
7. 最后处理表达精化：时态、虚拟语气、冠词和其他词法细节。

## 学习型知识库骨架

| 层级 | 作用 | 你要问的问题 |
| --- | --- | --- |
| 例句库工作台 | 快速查某个知识点的例句 | 这个知识点有没有标准例句和易混例句？ |
| 语法总览 | 建立颜色规则和总判断流程 | 这个成分在句中做什么？ |
| 词性之间的修饰关系 | 建立“修饰对象 → 功能”的判断方法 | 它具体修饰谁？ |
| 简单句 | 找主干和五大句型 | 谓语是谁？主干是否完整？ |
| 从句 | 处理“句子进入句子” | 从句整体做名词、形容词还是副词？ |
| 非谓语 | 处理“动词降级” | 这个动词形式为什么不是谓语？整体做什么功能？ |
| 介词短语 | 处理介词后的名词性成分 | 介词短语整体修饰名词，还是修饰动作 / 状态？ |
| 表达精化 | 处理时态、语气、词法 | 时间、态度、指称是否影响理解？ |
| 易混对比 | 集中处理真实阅读卡点 | 两个候选判断怎么区分？ |

## 查询口诀

分析句子时先找谓语，再找主干；修饰名词看黄色，修饰动作或整句看绿色；占名词位置看红色；动词形式但不是谓语看紫色。

## 实战分析口诀

经济学人句子分析时，按下面顺序走：

```text
找谓语 -> 定主干 -> 判断基本句型 -> 剥离定语/状语/补语
-> 判断从句 -> 判断非谓语 -> 处理易混点 -> 顺译
```
