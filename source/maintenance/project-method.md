# 项目方法论：学习体系与实战分析分工

本项目的目标不是整理一套孤立讲义，而是形成一套可以拿去分析真实英文文章的语法判断系统。

## 整理方法

本项目采用“任务导向 + 功能语法 + 例句检索 + 实战回填”的整理法。它不是照搬传统语法书目录，而是围绕真实阅读时的判断动作来组织知识。

| 方法 | 核心问题 | 落地方式 |
| --- | --- | --- |
| 任务导向整理 | 读真实英文时先需要判断什么？ | 先找谓语和主干，再处理复杂成分，最后处理时态、虚拟、词法等表达细节。 |
| 功能语法归类 | 这个结构在句中做什么？ | 从句、非谓语先归入名词性、形容词性或副词性功能；介词短语对外先走形容词性或副词性路线，再按需补充表语、必要地点补足等二级标签。 |
| 认知负荷控制 | 阅读时怎样不被说明文字打断？ | 每章固定按“结论卡 → 核心本质 → 判断步骤 → 类型速查 → 具体类型 → 易混对比 → 实战提示 → 关联入口”展开；项目使用说明放最后。 |
| 例句检索 | 学习后怎样快速查例句？ | 例句库工作台按章节和具体知识点双层筛选，正文只保留代表例句。 |
| 实战反馈闭环 | 经济学人里卡住的句子怎么沉淀？ | 对话中解决卡点后，按知识点回填例句、易混点或判断步骤。 |

## 当前知识骨架

HTML 学习页按下面顺序组织。例句库工作台放在页面最前面，服务快速查询；知识体系正文仍按判断顺序展开。

1. 例句库工作台：按章节和具体知识点查例句。
2. 语法总览：功能颜色、判断总流程、经济学人实战入口。
3. 词性之间的修饰关系：通过修饰对象判断形容词性或副词性功能。
4. 简单句：先掌握 Larry 五大核心句型，再补 SVA / SVOA、存在句、形式主语、被动和并列等真实文章表层入口。
5. 从句：先找从属关系和小句主干；再判整体功能，并区分引导成分是只标记从属关系、直接承担成分，还是连接先行词与内部空位。
6. 非谓语：动词降级后承担名词性、形容词性或副词性功能。
7. 介词短语：介词 + 名词性成分后，整体先进入形容词性或副词性路线；必要时追加更细的补足标签。
8. 时态、虚拟、词法：作为真实句子里的表达精化层。
9. 易混对比：集中处理 that / what、which / where、同位语从句 / 定语从句等卡点。
10. 项目使用说明：源文件、维护规则、经济学人对话格式等放在最后。

## 三层结构

| 层级 | 作用 | 使用场景 | 维护原则 |
| --- | --- | --- | --- |
| Larry 主线 | 项目的学习顺序和判断引擎 | HTML 学习页、Markdown 主讲义、语法判断流程 | 保持主线稳定，不因补充材料随意重排章节。 |
| 文法俱乐部旁注 | 理论底座、术语来源、细节补强 | 遇到概念需要理论解释时查阅 | 先做章节对照，不大段搬入正文；等 Larry 视频资料稳定后逐章补旁注。 |
| 经济学人实战 | 用真实文章检验语法体系 | Codex 对话框中的句子分析 | 不做网页工作台；在对话中按固定流程输出分析。 |

## 当前结论

不要等所有 Larry 视频都补齐后才重构项目结构；但也不要现在就把《文法俱乐部》的细节大量写进各章节。

更稳的顺序是：

1. 现在先建立“书课对照、术语对照、分析协议”三类索引。
2. 后续继续补 Larry 视频资料，仍以 Larry 主线为准。
3. 等某一块 Larry 内容稳定后，再补对应的《文法俱乐部》旁注。
4. 在经济学人分析中反复卡住的点，优先回填到语法库。

## 自主更新流程

来源视频：V18 BV1D1421m7o6；V23 BV13v4y147P4。当前仅依据视频标题和公开简介建立方法论入口，具体视频画面规则待补。

后续 Codex 自主更新项目时，按这个顺序执行：

1. 先读取 `source/sources/video-source-index.md`，确认目标视频和证据等级。
2. 如果有 A 级证据，更新规则、例句和分析。
3. 如果只有 B 级证据，只建立专题入口和待补方向。
4. 如果只有 C 级证据，不写具体规则。
5. 如果正文已有例句但来源未逐条确认，先登记到 `source/sources/example-source-audit.md`。
6. 每次优先更新 `source/content/*.md`，HTML 等用户确认后再同步。
7. 更新完成后运行格式检查，不自动提交推送，除非用户明确说“提交”或“推送”。

## 判断优先级

分析句子时按以下顺序判断：

1. 先按 Larry 主线找谓语、定主干、判五大核心句型；五类装不下时再加真实文章扩展标签，不能硬塞。
2. 再剥离定语、状语、补语、介词短语。
3. 遇到从句，先判断从句整体功能，再看连接词在从句内部承担什么成分。
4. 遇到非谓语，先确认它没有谓语资格，再判断它的整体功能，并尝试还原成从句。
5. 如果概念解释不够稳，再查《文法俱乐部》对应章节。

## Larry 主线溯源规则

Larry 视频是项目正文的第一来源。后续持续更新时，新增规则必须满足以下要求：

1. 能对应到具体视频序号和 BV 号，统一记录在 `source/sources/video-source-index.md`。
2. Larry 原例只能来自视频画面、用户截图或用户上传笔记。
3. 看不清的例句不补写，标记为“待补充截图例句”。
4. 不使用 Codex 自行创造的例句替代视频例句；用户明确批准的理论或真实阅读补充例句，必须标为“外部补充”并单独登记。
5. 规则可以提炼，但必须能回到视频、截图或笔记中找到依据。
6. 如果新增内容会改变章节结构、图示关系或网页模块位置，先向用户确认。

推荐在 Markdown 小节中保留：

```text
来源视频：Vxx｜BVxxxx｜课程小节标题
例句来源：视频截图 / 用户上传笔记 / assets/具体文件名
```

## 例句库规则

为了便于查询和记忆，正文不再把同一个知识点的多个例句平铺成一长串。统一处理方式：

1. 一个知识点只在主表或小节开头展示一个代表例句。
2. 同类多个例句收进“例句库”，正误或近义结构收进“对比例句库”。
3. 例句库中的每条例句只写最必要的判断，不展开成新的理论说明。
4. 例句库不改变知识体系层级，只服务于复习和查找。
5. 后续 HTML 展示也按同一原则：主页面轻量，展开后看多个例子。
6. 正文例句统一使用“Larry 原例 / 校准表达 / 纠错对比 / 依赖语境 / 外部补充 / 待确认”状态；有来源不等于适合作推荐表达。

## 知识点卡片模板

新增或重写知识点时，优先使用同一张卡片结构，避免章节风格散掉：

```text
知识点名称
一句话本质
判断问题
代表例句
拆句方法
易混对比
回到章节 / 关联知识点
```

如果某个知识点已经有多个例句，正文只保留代表例句；其余例句进入例句库工作台或对应小节的“例句库 / 对比例句库”。

章节级的“记忆重点、判断法、判断流程、判断口诀、复习卡”统一合并为一个“判断与记忆”模块。具体知识点不可替代的操作规则，例如补语检验、定语从句判断四步、until 判断，可以保留在对应专题内部，但不再另设重复的章节总结。

## 正文唯一归属

同一个总领规则只完整解释一次。其他章节只保留本章必需的判断，不再复制整张总表。

| 内容 | 唯一完整归属 |
| --- | --- |
| 功能颜色、全局分析流程、功能与形式的判断原则 | `content/grammar-overview.md` |
| 从句类型及功能 × 表现形式矩阵 | `content/clause-overview.md` |
| 修饰对象与形容词性 / 副词性判断 | `content/modification-relations.md` |
| 谓语、主干、Larry 五大核心句型、真实文章扩展骨架、补语检验 | `content/simple-sentence.md` |
| 从句本质、三类从句、连接词内部功能 | `content/clause-overview.md` |
| 各类从句的具体规则 | 对应的名词性、形容词性、副词性从句专题 |
| 跨章节易混判断 | `content/clause-confusions.md` |
| 从句、非谓语、介词短语的横向对照 | `content/clause-overview.md` 的“功能 × 表现形式矩阵” |
| 项目使用、来源和维护说明 | HTML 最后一章及 `source/` 非正文目录 |

专题章节结尾可以提供关联入口，但不得再次复制全局矩阵、三类从句总表或总判断流程。

## 统一章节结构

正文专题统一按下面顺序组织；八个章节级模块均保留，具体小节可按知识内容增减，但不得用多个近义标题重复承担同一职责。

```text
本章结论卡
核心本质
判断步骤
类型速查表
具体类型
易混对比
经济学人分析提示
关联入口
```

“本章结论卡”固定回答五个问题：

1. 一句话本质是什么？
2. 核心公式是什么？
3. 从哪个问题开始判断？
4. 哪一个代表例句最能说明规则？
5. 最容易和什么混淆？

每章只保留一个章节级总结模块。具体知识点仍可保留不可替代的局部检验法，但不要再另设“一页记忆卡”“学习重点”“总口诀”等同义总结。

## 经济学人实战回填

经济学人阅读中的句子分析不直接变成大段正文。只有当同类卡点反复出现时，才回填到知识库：

1. 记录卡住的结构和原句出处。
2. 判断它对应哪个知识点，例如宾补、同位语从句、非谓语状语、介词短语后置定语。
3. 如果现有知识点已经足够，只把句子加入例句库或学习卡片。
4. 如果现有判断步骤不够清楚，再补充“判断问题”或“易混对比”。
5. 不整篇保存经济学人文章，只保存必要句子、出处和自己的分析。

## 冲突处理

如果 Larry 和《文法俱乐部》的讲法顺序不同：

- HTML 和主讲义仍按 Larry 主线组织。
- 在旁注里说明《文法俱乐部》的对应章节和补充角度。
- 不把“顺序不同”视为理论冲突。

如果术语不同：

- 项目正文统一使用大陆常见术语：主语、宾语、从句、短语、介词、不定式。
- 文法俱乐部术语保留在术语对照表中。

如果判断口径不同：

- 先以项目当前判断流程为准。
- 把差异记录为“旁注”，等同类句子出现多次后再决定是否修改主线。
