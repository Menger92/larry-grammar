# Larry 视频资料索引与溯源表

本文件用于约束项目后续更新：所有 Larry 主线内容必须能追溯到具体视频、截图或用户上传笔记。视频顺序来自 B 站合集《半个月，搭建你的英语语法体系》。

合集链接：https://space.bilibili.com/19873195/lists/1700983?type=season

校准时间：2026-05-25。

## 使用规则

1. 新增知识点时，先在本表确认视频序号、BV 号和课程小节。
2. 写入 Markdown 时，在小节开头保留“来源视频”。
3. 例句只能来自视频画面、用户截图或用户笔记；看不清的例句不补写，标为“待补充截图例句”。
4. 不凭记忆或通用语法书自行创造例句。
5. 如果只提炼规则，必须能对应到视频标题、截图或笔记图片。
6. 如果涉及结构性调整，例如章节顺序、图示关系、HTML 模块位置，先向用户确认。

## 证据等级

| 等级 | 含义 | 能写入的内容 |
| --- | --- | --- |
| A | 视频画面 / 用户截图 / 用户笔记中能直接看到 | 可以写规则、例句和分析。 |
| B | B 站公开标题、简介、合集顺序能确认 | 只能写入口、主题归类和待补方向。 |
| C | 尚未取得明确画面或笔记 | 只保留待补，不写具体规则和例句。 |

## 推荐来源标注格式

Markdown 小节中推荐使用：

```text
来源视频：V10｜BV1AN411H7ag｜3.4 形容词性从句（上）
例句来源：视频截图 / 用户上传笔记 / assets/具体文件名
```

如果同一条规则来自多个视频，写成：

```text
来源视频：V10 BV1AN411H7ag；V11 BV1534y1N7Zd
```

## 更新顺序

1. 先补 Larry 主线视频。
2. 每次只处理一个明确小节，避免跨章节混写。
3. 先更新 `source/*.md`。
4. 例句来源先登记到 `source/example-source-audit.md`，确认后再扩写分析。
5. 用户确认章节内容稳定后，再同步 `web/app.js`。
6. 图片或图示使用 `web/assets/`，原始笔记和截图保留在 `assets/`。
