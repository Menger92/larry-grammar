## 维护规则

- 新增图片时，先确认它属于哪个视频，再接在对应主题的最后一个序号后面。
- 如果一张图片跨两个小节，以主要内容所属的小节命名。
- Markdown 源文件只提炼清晰可辨认的规则；需要看完整手写例句时，回到本文件夹查看原图。
