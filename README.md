# Larry 教材 Web 项目

这个结构用于 GitHub 和两台电脑同步维护。

## 目录

- `source/`：Markdown 源文件，后续主要编辑这里。
- `web/`：HTML 查询页面。
- `assets/`：图片素材。
- `docs/`：Word、Excel 等导出文件可放这里。

## 推荐工作流

1. 修改 `source/*.md`，其中 `source/full-summary.md` 是完整讲义主文本。
2. 若需要网页同步展示，再更新 `web/app.js` 中对应模块。
3. 用浏览器打开 `web/index.html` 查询。
4. 用 GitHub 保存版本历史。

## 展示原则

- 网页中的课程截图不直接使用原始截图，而是重绘成统一风格的信息图。
- 颜色标注使用浅底深字标签，避免纯色文字导致阅读困难。
- HTML 是查询版；Markdown 是源文件；Word/Excel 是导出版。

## 颜色规则

这是本项目的硬性规则。后续新增内容、网页展示、Markdown 源文件、Word/Excel 导出版，都必须严格按照以下对应关系标注。

- 名词性成分：红色
- 形容词性成分：黄色
- 副词性成分：绿色
- 非谓语 / 不定式：紫色
