## Reading Strategy

1. If the user asks for direct sentence analysis, do not read every project file.
2. Start from the sentence itself and the default workflow.
3. Read project sources only for the controlling topic or when the judgment is uncertain.
4. If a rule is not found in the project, say it is an external grammar supplement.
